## 📌 About This Repository

This repository contains three projects created to practise web data
extraction with Python. Each project explores a different use case and
helps build practical skills in collecting, inspecting, and organizing
web-based information.

## 🚀 Getting Started

### Prerequisites

-   Python 3.x
-   Git (optional, if cloning the repository)
-   Any API key or package required by a specific project

### 1. Clone the repository

``` bash
git clone <your-repository-url>
cd Web-Scraping-Projects
```

Replace `<your-repository-url>` with the HTTPS URL of your GitHub
repository.

### 2. Create a virtual environment (recommended)

**Windows**

``` bash
python -m venv .venv
.venv\Scripts\activate
```

**macOS / Linux**

``` bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install dependencies

If you have a `requirements.txt` file:

``` bash
pip install -r requirements.txt
```

If each project has different dependencies, install the packages listed
in that project's own README instead. Do not add packages to
`requirements.txt` unless the code actually uses them.

### 4. Run a project

Open the project folder and follow the instructions in its README. For a
Python script, the command may look like this:

``` bash
python main.py
```

Replace `main.py` with the actual script filename.

## 📋 Project Documentation Checklist

For each project, document: - Purpose and what information it extracts -
Website or data source used - Python packages and setup instructions -
Exact command to run the script - Example output or screenshot - Any API
key or environment variables required

Never commit API keys, passwords, access tokens, or other secrets. Store
private values in environment variables or a local `.env` file, and add
`.env` to `.gitignore`.

## ⚖️ Responsible Scraping

Use these projects responsibly: - Check a website's Terms of Service and
`robots.txt` before scraping. - Follow applicable laws and the website's
access rules. - Respect rate limits and avoid sending excessive
requests. - Do not collect private, sensitive, or unnecessary personal
information. - Use an official API when one is available and
appropriate.
